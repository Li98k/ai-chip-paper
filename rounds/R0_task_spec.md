# 任务书：基于三极管放大电路的 AI 推理芯片方案论证

用户原始设想（逐字保留关键表述）：
> 现代的 AI 模型几乎都是依赖 GPU 进行推理的，需要设计一个新的芯片，直接将参数写入芯片。
> 依据三极管放大电路的原理，上一层连接线为特定的电阻，电阻根据模型的参数计算得出；
> 上一层所有电阻线都连接到下一层的节点三极管上；如果多条连接线连接后阻值发生了变化，
> 对于当前这个节点上的三极管放大信号数值就会发生变化，通过的电流也会变化。
> 以此为基础设计一个 AI 芯片。

任务要求：
1. 对方案进行论证（电路数学 + 器件物理 + 工艺缩放三个层面）；
2. 搜索资料（arXiv / 期刊 / 已发表芯片），确认可行性与先例；
3. 给出优缺点清单与结论（可不可行、何种规模、何种条件下）；
4. 反复审核论证，总论证时间 ≥ 5 小时，多轮记录（见 LOG.md）。

## 方案的形式化（我先把用户的白话翻译成电路模型）

对某一层的一个输出神经元节点 N（对应一个三极管 Q）：
- 上一层 j 个神经元各输出电压/驱动电流信号 x_j（激活值）；
- 连接线 j 是一根电阻 R_j，其阻值由模型权重 w_j 决定：R_j = f(w_j)；
- 所有 R_j 汇聚到 Q 的输入端（基极 B，经 V_BE 偏置），
  节点电流 I_B = Σ_j I_j，I_j 由 x_j 与 R_j 决定；
- 集电极电流 I_C = β·I_B（放大），输出 = I_C（或经负载电阻转为电压）。

关键待证问题：
Q1. 什么样的 R_j = f(w_j) 映射使 I_B 恰好等于加权和 Σ w_j·x_j？
    （答：取电导映射 G_j = w_j/R0，即 R_j = R0/w_j，且 x_j 以电压源 + 串联电阻形式注入，
      或 x_j 以电流源形式注入。必须区分两种注入拓扑。）
Q2. 负权重怎么办？（单电阻网只能正电导 → 需要差分/双网络/符号编码）
Q3. 三极管在线性区的范围有多大？β 的离散与温漂影响？基极电流预算 vs 扇入数？
Q4. 噪声（热噪声 kT、1/f、ADC/DAC）能支持几位有效精度（INT8/INT4/FP16）？
Q5. 规模：7B/27B 模型需要多少电阻、多大面积、多高成本？单片能否放下？
Q6. LLM 特有结构（attention 的 KV cache、变长序列、softmax）与固定模拟硬件的匹配度？
Q7. 与已知先例（模拟 CIM、RRAM/PCM 存内计算、TrueNorth/Mythic/NorthPole、
    BJT 神经网络电路史）相比，本方案的新意与差距？
