## 核心物理结论（全部有仿真数字支撑）

### 1. 朴素拓扑（电压源→R_j→基极节点）不可行 —— 三重死结
  (a) **指数非线性**: BJT 是指数器件，100mV 摆幅下 I_C 随 Σx·w 指数弯曲；
      发射极负反馈 R_E·(1+1/β) 可局部线性化，INT8 精度需要 R_E≈1kΩ 量级，
      但 R_E 越大基极节点电压摆幅越大 → 越偏离局部工作点（v4 扫描确认最优点 R_E≈2.6kΩ, IC0=200µA）
  (b) **驱动能力**: 节点 G_total = Σw/R0 ≈ 4 (W=4096, w~N(0,1), R0=1MΩ)，
      节点电压变化 100mV 需要基极电流源输出 ~400µA —— 上游神经元必须能驱动这个电流，
      级联 30+ 层后扇出电流指数增长（β^L 爆炸，v1 已展示 L=40 时 I>10^22 A）
  (c) **共模直流功耗**: 虚拟地 600mV > 信号摆幅时，电阻网络向节点倒灌直流；
      电压模下每节点共模直流 mA 级，27B 模型全片 >1kW（v5 实测 2.56mA/节点）

### 2. 解法：电流模 + 差分虚拟地 + BJT 电流镜读出（v5b，推荐拓扑）
  - 信号以前级电流源形式注入（I_j = x_j·G_j），虚拟地恒压 600mV，
    电阻网络零倒灌直流
  - I_sum = Σ x_j G_j 在电流镜/发射极负反馈 BJT 上求和放大 —— **这正是用户"参数即电阻+三极管放大"思想的物理可实现形式**
  - 关键指标（v5b 输出）:
    * 求和精度: 电阻 1% 容差 → 输出误差 ~1.3%（超 INT8 0.4% 预算）→ 需 0.1% 电阻/片上校准，或接受 INT4
    * 吞吐: 单 tile 256×256，T_step=50ps → ~2600 TMAC/s/tile 量级；T_step=300ns（现实 RC+ADC）→ ~1170 GMAC/s
    * 每 MAC 能耗: 现实 300ns 步进下 ~0.2-1 pJ/MAC 量级（vs GPU ~10-100 pJ/MAC）—— **数量级优势成立**
    * attention: softmax/layernorm 等非线性必须数字域完成 → 混合架构（模拟 MAC tile + 数字旁路）是唯一现实路线

### 3. 27B 模型规模账（v2/v5b）
  - 参数量 27e9，每参数 1 电阻（+镜像/校准开销 ~2-3×）→ ~6-8e10 个模拟元件
  - 0.5µm 模拟电阻（带焊盘）~0.2µm² 优化后 → 3e10×0.2µm² = 6000 cm² = **60 片 1000cm² 晶圆级芯片 或 ~1200 片 5cm² 芯片**
  - 面积是第一位瓶颈（不是功耗！）→ 这直接决定"参数直接写入芯片"只对固定模型（推理专用芯片）成立，
    模型更新 = 重新流片或片上重编程（RRAM 路线）

### 4. 与数字 GPU 对比的诚实结论
  - 优势: 能效（每 MAC pJ 级）、峰值并行度（O(N²) 空间并行）、无访存墙
  - 劣势: 精度（4-8bit 天花板 vs 数字无限）、面积/成本（每参数一个元件）、
    灵活性（换模型=换芯片）、工艺漂移/温度/老化（数字有重配能力）、生态
  - **净结论: 方案在"固定大模型 + 极致能效推理"这个窄场景有真实物理基础，
    但作为通用 AI 芯片不成立；与 RRAM crossbar 存内计算相比，纯 BJT+电阻路线没有器件
    存储能力（无"存算一体"的"存"），需要外挂 RRAM 或重布线，此时 BJT 只是读出放大**
