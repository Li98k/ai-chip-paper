# R0 论证轮（2026-10-09 22:12 起）

## 1. 方案的形式化（电路模型）
用户白话 → 电路：
- 上一层 j 个神经元输出电压 x_j（模拟量，激活值）
- 连接线 j = 电阻 R_j，阻值编码权重：取电导映射 R_j = R0/w_j（G_j = w_j/R0）
- 所有 R_j 汇入下一层神经元 Q 的基极节点 B
- Q（BJT）+ 发射极电阻 R_E：I_C ≈ (V_B − V_BE)/R_E → 输出电流 ∝ 节点电压
- 节点电压 KCL：V_B = [Σ_j x_j/R_j + V_BIAS/R_BIAS] / [Σ_j 1/R_j + 1/R_BIAS]
  ⇒ **ΔV_B 天然等于加权和 Σ w_j·Δx_j 的加权平均** —— 电阻网络自己完成了"乘加"，
    三极管只做"放大/整形/电平转换"。

## 2. 第一轮数值发现（sim/sim_v1.py, sim_v1b.py, Ebers-Moll 全模型）
### 发现 F1（重要，方案成立的数学基础）
加权求和由**电阻分压**完成，与三极管指数特性无关：
  V_B = (Σ x_j/R_j)/(Σ 1/R_j)（偏置抵消后）
这是线性运算，数学上严格成立。BJT 不是"求和器"，是"放大器/读出器"。
→ 用户直觉"阻值变化 → 放大信号变化 → 电流变化"成立，但机理要修正：
  先有节点电压的加权平均（线性），再经 BJT 指数放大（非线性读出）。

### 发现 F2（方案的核心矛盾 #1：BJT 是指数器件，直接放大必非线性）
无 R_E 时，100mV 输入摆幅 → I_C 变化 40 倍（exp(100mV/25.9mV)=47.7），完全不可用。
必须加发射极负反馈 R_E：
  加 R_E=100Ω 后，全 Ebers-Moll 精确解（非小信号近似）线性拟合残差 = **0.03%**
  （输入 0→100mV 满摆幅，W=4096）→ 负反馈把指数器件变成线性放大器，成立。
  代价：增益 ≈ 1/R_E，与 β 无关（β 只影响偏置电流大小，不影响精度）→ β 离散/温漂问题被负反馈大幅抑制。

### 发现 F3（核心矛盾 #2：v1 设计点非物理 → 驱动电流瓶颈）
R0=40kΩ、W=4096 时：
  - 节点等效电阻 R_eq = 1/Σ(1/R_j) ≈ 6.4Ω（4096 支并联）
  - 每个基极节点要吸入 I ≈ V_B/R_eq ≈ 0.7V/6.4Ω ≈ 110mA 级 → 每个上一级集电极
    需驱动 x_j·N/R0 ≈ 5mA（N=4096）→ 全片数百安培，物理不可行。
  → 结论：R0 必须做大到 ≥1MΩ（节点吸入 ~200µA，每支 50nA，每神经元驱动 ~200µA 可接受），
    或采用交叉阵列（crossbar）拓扑 + 列驱动。这是本方案可工程化的第一道门槛。

### 发现 F4（噪声，sim_v1b B 节）
R_eq=6.4Ω（R0=40k）时输入热噪声 412nV/√(1.6MHz) → 若满幅 100mV，SNR≈92dB
（注意：此数字因 F3 工作点错误偏乐观，v2 用 R0=1MΩ 重算）。
初步判断：电阻热噪声不是瓶颈，**1/f 噪声、偏置电路噪声、ADC 位数**才是。

### 发现 F5（电阻容差，C 节 Monte Carlo，300 次）
1% 电阻 → Σwx 输出误差 mean 0.009%、p95 0.021%（W=4096 求和平均效应）
0.1% → p95 0.002%
→ 大扇入求和本身有"平均误差"效果：N 支 1% 电阻的加权和误差 ~1%/√N 量级。
  结论：1% 片上多晶电阻（激光修调可达）→ 等效 >8bit 精度，满足 INT8 LLM 推理。

### 发现 F6（级联增益，D 节）
电流直接级联 L 层：I_L = I_1·β^L，L=2 即达 1A，L=3 爆炸 →
  **必须逐层归一化**（每层输出经 ADC/电流镜复位到固定摆幅）。
  归一化位数 = 逐层量化位数（INT8）。这正是所有模拟 CIM 芯片（Mythic/NorthPole）的
  标准做法 —— 用户方案与工业界实践在此汇合。
